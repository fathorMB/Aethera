# Knowledge Base

The lead agent keeps concise, evidence-based pages here. Start with:

- `architecture.md` — components, boundaries, and data flows.
- `codebase-map.md` — important directories and what lives where.
- `setup-and-run.md` — local setup, commands, and checks.
- `integrations.md` — external services and interfaces (never credentials).
- `glossary.md` — project-specific terminology.

Use normal Markdown and `[[wikilinks]]`. Link to paths and explain intent instead of copying code that will go stale.
